Project Overview & Architecture

The portfolio is a single-file HTML website built with pure HTML, CSS and JavaScript — no frameworks, no build tools. This keeps it lightweight, fast to load and easy to maintain. Everything required is in one folder that can be deployed by dragging and dropping onto Netlify.

Live URL: gauravsharma-digitalstrategist.netlify.app
Booking: calendly.com/imgauravraj21/30min

Architecture

ComponentTechnologyPurpose
FrontendHTML / CSS / Vanilla JSThe entire website — single index.html file
NEXUS BackendNetlify Function (Node.js)Secure API calls to Claude AI
AI ModelClaude Haiku (Anthropic)Powers NEXUS chatbot intelligence
HostingNetlifyStatic site hosting + serverless functions
SchedulingCalendlyBook a Strategy Call feature
PodcastsHTML5 Audio APIBlog listen functionality
VideoHTML5 Video + YouTubeHero background + keynote videos

Key Design Decisions

  • Single HTML file — no build step, no dependencies, works offline
  • All assets use relative paths — folder can be moved without breaking links
  • Dark navy + gold colour scheme — premium executive positioning
  • Mobile responsive at 1024px, 768px and 480px breakpoints
  • NEXUS API key stored in Netlify env vars — never exposed in browser

How Read works

Clicking a blog card or the Read button opens a full-screen modal overlay with the complete article text. Click outside the modal or press the ✕ button to close.

How Listen works

Inside the modal, press the 🎧 Listen button to play the MP3 podcast. The button changes to ⏹ Stop while playing. Only one podcast plays at a time. Audio stops automatically when the modal is closed.

To add a new blog: See Section 15 — Adding New Blog Posts.

NEXUS AI Chatbot

NEXUS is Gaurav's AI digital twin — a floating chat widget powered by Claude Haiku. It answers questions about Gaurav's career, expertise, achievements and availability. It maintains conversation context within a session.

How NEXUS works

1
User sends a message

Via the input box or by clicking one of the quick-reply chips (BSS expertise, CVM programs, AI work, Book a call)

2
Frontend calls Netlify Function

Sends the message + last 8 conversation exchanges to /.netlify/functions/nexus

3
Netlify Function calls Claude API

Uses Claude Haiku with a detailed system prompt containing Gaurav's full profile. API key is kept server-side.

4
Response displayed

After a typing indicator, the AI reply appears. Conversation history is maintained for follow-up questions.

NEXUS knowledge base (system prompt covers)

  • Full career history (5 roles)
  • Key achievements & metrics
  • All 8 areas of expertise
  • 9 certifications
  • 12 global clients
  • 3 blog summaries
  • Contact & booking details
  • Location & availability

API Configuration

SettingValue
Modelclaude-haiku-4-5-20251001
Max tokens300 per response
Conversation memoryLast 8 exchanges (16 messages)
API key locationNetlify Environment Variables
Environment variable nameANTHROPIC_API_KEY
Function filenetlify/functions/nexus.js

Updating NEXUS knowledge

To update NEXUS with new information (new clients, achievements, roles), edit the SYSTEM_PROMPT constant at the top of netlify/functions/nexus.js, then redeploy.

Cost awareness: Claude Haiku is very affordable (~$0.25 per 1M input tokens). A typical NEXUS conversation costs less than $0.001. Monitor usage at console.anthropic.com

Calendly — Book a Strategy Call

Three buttons on the site open the Calendly booking page: Book a Call (nav), Book a Strategy Call (hero), and Schedule Now (contact section).

Calendly URL: calendly.com/imgauravraj21/30min

If the calendar shows wrong dates

1
Log in to Calendly

Go to calendly.com and sign in

2
Edit the 30min event

Click the event type → Edit

3
Check Availability settings

Set date range to "Indefinitely into the future". Reduce minimum scheduling notice to 1–24 hours.

4
Save & Close

Changes take effect immediately — no redeployment needed

Deployment — Netlify

How to deploy / redeploy

1
Go to Netlify Deploys page

app.netlify.com → gauravsharma-digitalstrategist → Deploys

2
Drag and drop the folder

Drag the entire Portfolio Website/ folder onto the deploy area on the page

3
Wait ~20 seconds

Netlify deploys automatically. The live URL updates immediately.

VariableValueWhere to set

How to Update Content

Update a career card

Open index.html in a text editor. Search for the company name (e.g. Tecnotree Corporation). Update the role title, tags, or bullet points in the cc-front or cc-details-inner div.

Update contact details

Search for imgauravraj21@gmail.com or +91-6363705230 in index.html. Update all occurrences. Also update netlify/functions/nexus.js system prompt to keep NEXUS in sync.

Update the profile photo

Replace img_0.jpg with your new photo (keep the same filename and 3:4 portrait ratio). Redeploy.

Replace a company logo on career cards

Drop the new PNG into Career Card Images/ with the same filename as the existing one. Redeploy. No code changes needed.

Replace expertise card backgrounds

Drop the new image into Expertise Card bg/ with the exact same filename. Redeploy.

Update hero stats (19+ years, $130M+, etc.)

Search for the stat text in index.html and update in place. Also update the NEXUS system prompt in netlify/functions/nexus.js.

Troubleshooting

IssueLikely CauseFix
NEXUS not respondingAPI key missing or expiredCheck ANTHROPIC_API_KEY in Netlify env vars. Redeploy after updating.
NEXUS says "connection issue"Netlify function cold start or API errorTry again — cold starts resolve in ~2 seconds. Check Netlify function logs.
Videos not playing in carouselBrowser autoplay blockedVideos are muted, so autoplay should work. Check browser console for errors.
Hero video not showingFile path issue after redeployEnsure Portfolio/Gaurav_1.mp4 is inside the deployed folder.
YouTube Error 153Video embedding disabled by ownerChange to window.open() instead of iframe embed.
Calendly shows wrong datesCalendly availability settingsUpdate scheduling notice in Calendly dashboard (Section 12).
Nav links not scrollingSection ID missingEnsure target section has the correct id attribute (e.g. id="contact")
Blog Listen not workingMP3 file missing or wrong pathCheck Portfolio/Podcast_Experience_1/2/3.mp3 exists in deployed folder.
Images not loading after deployCase-sensitive filenamesNetlify is case-sensitive. Ensure filenames match exactly including spaces.
Site looks broken on mobileViewport issueTest in Chrome DevTools mobile view. Breakpoints: 1024px, 768px, 480px.

2
Click "Logs & metrics"

Then "Function logs" to see NEXUS function execution logs and any errors
